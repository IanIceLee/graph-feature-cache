# Contributing

- Do not commit raw datasets, model checkpoints, run logs or result CSVs. They are ignored
  by `.gitignore` and are not covered by the Apache-2.0 license.
- Run `pytest -q` and `python core/examples/synthetic_demo.py` before opening a pull request.
- Keep the public code free of absolute paths, credentials and private host addresses.
- Use the Apache-2.0 license for contributed code.
