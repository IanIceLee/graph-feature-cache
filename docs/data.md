# Data

Raw data are not redistributed. See `data/README.md` for the expected local layout,
public sources, and the reference checksums. `scripts/check_data.py` validates the layout.

The Apache-2.0 license applies to the code only; it does not apply to METR-LA, PEMS04 or
PEMS08.

`calibration/calibration.json` is the frozen summary used by the drivers; the raw
`cost_samples.csv` is not shipped.
